# COVID-19 Data Analysis (Python)

This project analyzes global COVID-19 data to find meaningful trends and relationships between confirmed cases, recoveries, and deaths.

## Steps Performed
1. Data Cleaning and Preprocessing
2. Statistical Analysis (correlations and patterns)
3. Visualization of Top 10 Countries
4. Integration-ready output for Streamlit dashboard

## Files
- `data/covid_data.csv` — Raw dataset
- `data/country_summary.csv` — Cleaned summary
- `data/top10_confirmed.png` — Top affected countries
- `data/deaths_vs_recovered.png` — Death vs Recovery trends
